# PR9 Timeline Gestures

PR9 adds direct timeline editing through the existing editor command gateway.

- Horizontal clip-body dragging moves a clip only on its current track.
- Dragging near a clip edge trims that source edge.
- Double-clicking a clip splits at the clicked timeline position.
- The existing one-second snap control applies to these gestures.

Cross-track drag-and-drop is intentionally not implemented.
