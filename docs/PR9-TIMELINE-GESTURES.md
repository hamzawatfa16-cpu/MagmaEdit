# PR9 Timeline Gestures

PR9 makes the professional timeline directly editable through the existing editor command gateway.

- Drag a clip horizontally to move it only on its current track.
- Drag near the left or right edge to trim that source edge.
- Double-click inside a clip to split it at the clicked timeline position.
- Existing one-second snapping applies to move and trim gestures.

Cross-track drag-and-drop is intentionally not implemented.
